# Prompts images produits — un fichier par visuel

Gemini ne rend qu'une image par tour : générer les 18 visuels **un par un**, dans l'ordre.
Chaque fichier contient le prompt complet, autonome, à coller tel quel.

Le cadrage commun et l'intégration dans l'app sont décrits dans [../prompts-images-produits.md](../prompts-images-produits.md).

**Ordre conseillé** : commencer par `p1` (image de référence), puis joindre le résultat aux 17 suivants
avec la phrase de cohérence de série présente en bas de chaque fichier.
